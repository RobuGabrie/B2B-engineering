# B2B Engineering website

Presentation site for a B2B engineering company (hardware, embedded, computer vision, custom software). Astro + Tailwind, RO at `/`, EN at `/en/`.

Read before working:
- `docs/PROGRESS.md`: **current status, decisions, user feedback, next step — start here**
- `docs/BRIEF.md`: the original client brief (content source of truth)
- `docs/RULES.md`: workflow, content, visual and technical rules
- `docs/SKILLS.md`: skills and tools available
- `PLAN.md`: structure and the step-by-step build plan

Commands: `npm run dev` (localhost:4321; for agents: `npx astro dev --background`, stop with `npx astro dev stop`), `npm run build`, `npm run check` (types), `npm run preview`.
